[Q] Který z následujících popisů nejlépe odpovídá proměnné v programování?
[x] Jméno, do kterého program uloží hodnotu, kterou lze později použít nebo změnit.
[0] Speciální typ souboru.
[0] Vstupní klávesa.
[0] Název funkce.
[VYSVETLENI] Proměnná je pojmenované místo v paměti. Hodnotu do ní uložíme přiřazením (např. `x = 10`) a kdykoli později ji můžeme přečíst nebo přepsat.

[VYSVETLENI] Text (např. 'ahoj') je v Pythonu typu str (string). int jsou celá čísla, float desetinná čísla a bool logické hodnoty True a False.

[Q] Který operátor se v Pythonu používá pro umocňování?
[x] **
[0] ^
[0] //
[0] %
[VYSVETLENI] Umocňuje se pomocí `**`, např. `2 ** 3` je 8. Znak `^` je v Pythonu bitová operace XOR, `//` je celočíselné dělení a `%` zbytek po dělení.

[OBTIZNOST: lehká]
[Q] Která správná syntaxe zjistí, zda je x větší než 5?
[x] x > 5
[0] 5 or x
[0] x or 5
[0] x <= 5
[VYSVETLENI] Operátor `>` porovnává, zda je levá strana větší než pravá. Výsledkem je True nebo False. `<` a `<=` testují opačné nerovnosti a `or` je logické NEBO, ne porovnání.

[Q] Co vypíše příkaz `print(3 > 2)`?
[x] True
[0] False
[0] nic
[0] 0
[VYSVETLENI] Porovnání `3 > 2` je pravdivé, a proto má hodnotu True (typ bool). Python v tomto případě nevypíše číslo 0 ani nic jiného.

[Q] Jaký je výsledek výrazu `4 < 1`?
[x] False
[0] True
[0] 4
[0] 1
[VYSVETLENI] Čtyři není menší než jedna, takže porovnání dává False. Výsledkem porovnávacího operátoru je vždy hodnota typu bool, nikoli jeden z porovnávaných operandů.

[OBTIZNOST: lehká]
[Q] Který z těchto výrazů využívá logický operátor NEBO?
[x] a or b
[0] a && b
[0] a | b
[0] a + b
[VYSVETLENI] V Pythonu se logické NEBO zapisuje klíčovým slovem `or`. Zápis `&&` v Pythonu neexistuje (je z jazyků typu C či Java), `|` je bitové OR a `+` sčítání.

[OBTIZNOST: lehká]
[Q] Co vrátí výraz `5 == 5`?
[x] True
[0] False
[0] 5
[0] 0
[VYSVETLENI] Operátor `==` porovnává, zda se dvě hodnoty rovnají. Protože se rovnají, vrátí True. Pozor na rozdíl: jedno `=` je přiřazení, dvě `==` jsou porovnání.

[OBTIZNOST: lehká]
[Q] Co znamená klíčové slovo `and` v Pythonu?
[x] logické A
[0] bitový NOT OR
[0] přiřazení
[0] sčítání
[VYSVETLENI] Výraz `a and b` je pravdivý jen tehdy, když jsou pravdivé oba operandy. Přiřazení se zapisuje `=` a sčítání `+`.

[OBTIZNOST: lehká]
[Q] Co vypíše příkaz `print(True and False)`?
[x] False
[0] True
[0] 1
[0] True and False
[VYSVETLENI] Operátor `and` vyžaduje, aby byly pravdivé oba operandy. Jeden z nich je False, proto je celý výraz False.

---

[OBTIZNOST: lehká]
[Q] Co vypíše příkaz `print(True or False)`?
[0] False
[x] True
[0] 0
[0] žádný výsledek
[VYSVETLENI] Operátor `or` je pravdivý, pokud je pravdivý alespoň jeden z operandů. Zde je jedním z nich True, takže výsledek je True.

[Q] Co vypíše Python? `print(10 - 3*3)`
[x] 1
[0] 21
[0] -1
[0] 10 - 3*3
[VYSVETLENI] Násobení má přednost před odčítáním, takže se nejdřív spočítá 3*3 = 9 a potom 10 - 9 = 1. Výsledek 21 by vznikl, kdyby se nejprve odečetlo.

[x] "Hello"

[VYSVETLENI] Řetězec se v Pythonu zapisuje do uvozovek (jednoduchých nebo dvojitých). Bez nich by Python považoval Hello za název proměnné, hranaté závorky vytvářejí seznam a `Hello()` je volání funkce.

[x] False

[VYSVETLENI] Čísla 2 a 3 se nerovnají, takže porovnání dává hodnotu False.

---

[OBTIZNOST: střední]
[Q] Který výraz je pravdivý?
[x] True or False
[0] False and False
[0] False or False
[0] True and False
[VYSVETLENI] Výraz s `or` je pravdivý, když je pravdivý aspoň jeden operand, zatímco výraz s `and` vyžaduje oba. Jediný výraz s alespoň jednou hodnotou True spojenou pomocí `or` je `True or False`.

[Q] Jaký je datový typ výsledku výrazu `5/2` v Pythonu?
[x] float
[0] str
[0] bool
[0] dict
[VYSVETLENI] Běžné dělení `/` vrací v Pythonu vždy float, i když je výsledek celé číslo (např. `4/2` je 2.0). Celočíselné dělení `//` by vrátilo int.
