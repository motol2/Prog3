[Q] Který z následujících názvů proměnných je správně podle PEP 8?
[0] `pocetBodu`
[0] `PočetBodů`
[x] `pocet_bodu`
[0] `PocetBodu`
[VYSVETLENI] Proměnné a funkce se podle PEP 8 pojmenovávají malými písmeny a slova se oddělují podtržítkem (snake_case). Zápisy `pocetBodu` (camelCase) a `PocetBodu` (CapWords) se v Pythonu používají jinde, například pro třídy.

[0] `max_pokus`

[x] `MAX_POKUS`
[0] `Max_Pokus`
[VYSVETLENI] Konstanty se píší velkými písmeny a slova se oddělují podtržítkem. Python konstanty nehlídá, ale podle velkých písmen programátor pozná, že hodnotu nemá měnit.

[Q] Pro co se v Pythonu používá CamelCase (např. `MojeTrida`)?
[0] Pro názvy funkcí.
[0] Pro názvy proměnných.
[x] Pro názvy tříd.
[0] Pro konstanty.
[VYSVETLENI] Názvy tříd se píší ve stylu CapWords: každé slovo začíná velkým písmenem a bez oddělovačů. Funkce a proměnné používají snake_case a konstanty velká písmena s podtržítky.

[Q] Kolika mezerami se odsazuje kód v Pythonu podle PEP 8?
[0] 2 mezerami
[x] 4 mezerami
[0] 8 mezerami
[0] 1 tabulátorem

[Q] Který zápis volání funkce je správný podle PEP 8?
[0] `funkce(a,b,c)`
[x] `funkce(a, b, c)`
[0] `funkce( a, b, c )`
[0] `funkce (a, b, c)`
[VYSVETLENI] Za čárkou se píše jedna mezera, před čárkou žádná. Mezery se nedávají ani těsně za otevírací závorku a před zavírací, ani mezi název funkce a otevírací závorku.

[OBTIZNOST: střední]
[Q] Který zápis je správně podle PEP 8?
[0] `x=5+3`
[0] `x= 5+3`
[x] `x = 5 + 3`
[0] `x =5 + 3`
[VYSVETLENI] Okolo operátoru přiřazení se vždy píše po jedné mezeře z každé strany, a to stejně na obou stranách. U jednoduchých aritmetických výrazů se mezery okolo operátorů také doporučují. PEP 8 dovoluje mezery vynechat jen u operátorů s vyšší prioritou, např. `x = a*2 - 1`.

[Q] Který zápis seznamu je správně podle PEP 8?
[0] `seznam = [1,2,3,4,5]`
[x] `seznam = [1, 2, 3, 4, 5]`
[0] `seznam=[1, 2, 3, 4, 5]`
[0] `seznam = [ 1, 2, 3, 4, 5 ]`
[VYSVETLENI] Za každou čárkou následuje mezera a po hranatých závorkách se mezery nepíší. Okolo `=` jsou mezery, takže je správný pouze zápis s jednou mezerou za čárkou.

[OBTIZNOST: střední]
[Q] Který způsob importu je správný podle PEP 8?
[0] `import math, random, sys`
[x] `import math` ⏎ `import random` ⏎ `import sys`
[0] `import math; import random; import sys`
[0] `from math import *`
[VYSVETLENI] Každý import patří na samostatný řádek, což se lépe čte a kontroluje. Hvězdičkový import `from math import *` se nedoporučuje, protože zanáší do programu neznámé názvy a může přepsat již existující.

[Q] Jak se správně píše inline komentář podle PEP 8?
[0] `x = 5 #komentář`
[0] `x = 5# komentář`
[x] `x = 5  # komentář`
[0] `x = 5   #komentář`

[OBTIZNOST: těžká]
[Q] Jak se správně porovnává s hodnotou `None` podle PEP 8?
[0] `if x == None:`
[x] `if x is None:`
[0] `if x === None:`
[0] `if None == x:`
[VYSVETLENI] `None` existuje v programu jen jednou, a proto se porovnává identita operátorem `is`. Operátor `==` lze u vlastních tříd předefinovat a výsledek by se mohl lišit. Operátor `===` Python vůbec nemá a zápis je syntaktická chyba.
